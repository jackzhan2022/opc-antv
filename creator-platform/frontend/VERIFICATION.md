## 截图稳定性复核

初版列表截图拍摄于 Ant Design Spin 的退出过渡期：`.ant-spin-spinning` 已消失，但实测 `.ant-spin-container` 透明度仍为 `0.519092`，其 `::after` 遮罩透明度为 `0.384726`，导致整张表格发白。实际静态正文配色无误。

截图辅助函数现同时等待无 `.ant-spin-spinning`/`.ant-spin-blur`、内容透明度为 `1`、伪元素遮罩透明度为 `0`，并设置 `animations: 'disabled'`。只重跑涉及截图的三条工作流：`npm test -- --grep '公司共享|375px|服务错误' --reporter=line`，结果为 `3 passed (34.7s)`；七张截图均已重新生成，桌面/移动列表经再次目视检查对比正常。此轮仅改测试截图等待和本记录，未改业务/认证实现。

只读集成体验核对：登录状态页不自动发起授权；统一平台链接使用站点根地址；列表、新增、编辑、详情返回链接经 Umi 的 `/creators` base 解析；保存后进入详情，取消返回相应列表/详情，归档详情不能进入编辑表单。现有返回列表会重置筛选、分页和归档标签，因为列表状态仅保存在组件内；本轮按只读要求保留此行为。

## 原型结构对齐最终结果

上文为首版记录；本轮已恢复独立业务侧栏、资源库紧凑表格、两栏详情、四段编辑及职业/标签/角色页面。筛选、标签及分页现保存于URL，详情/编辑返回恢复；不把搜索关键词写入localStorage。末页唯一资料归档后会自动回到有效页，避免假空列表。

先以新增3项核心结构测试和缺失职业页面确认RED，再实现真实API页面；独立复核新增的末页归档及减少动态效果下弹窗均先复现失败，修复后最终双spec共25项通过（44.9秒）。减少动态效果使用极短动画时长保留结束事件，避免Ant Design弹窗停在opacity0；背景与弹窗表单使用不同name保证标签关联。

最终`npm run typecheck`退出0，Playwright自动生产构建退出0，`.last-run.json`为passed且无失败测试。新截图包含test-results下列表/详情/编辑的桌面与375px版本；配置页和弹窗在artifacts/configuration-visual。均为本地合成资料截图并由.gitignore排除，不作为生产身份验收证据。
