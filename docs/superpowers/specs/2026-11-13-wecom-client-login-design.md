# 企微客户端免扫码登录

日期：2026-11-13。延续用户已授权的企微登录开发及上一轮确认的双入口方案。

## 行为

- 在企微内打开平台，未登录且企微已配置时，自动开始企微网页授权。
- 后端从 User-Agent 中识别独立 `wxwork` 标记；企微客户端使用 `https://open.weixin.qq.com/connect/oauth2/authorize`、`snsapi_base` 和 `#wechat_redirect`。普通浏览器继续使用现有企业微信 Web 登录地址。
- 飞书入口保持原有行为。User-Agent 仅决定授权入口，不作为身份或角色证明。
- 两种入口共享同一服务端回调、授权码交换、企业校验、成员关联校验和会话签发，不增加数据库迁移。
- 授权错误页面不自动重试，展示已有错误提示；用户仍可手动重新登录。
- 主动退出后停留登录页，不触发免登回环。已有会话直接进入工作台；企微未开通时保留现有禁用入口。

## 实现边界

IdentityProvider 添加兼容的请求上下文重载；仅企微适配器根据客户端标记选择授权地址。OAuth state 使用32字节随机数的十六进制编码，以符合网页授权文档中的字母数字参数约定，仍绑定Session和提供方、五分钟有效、一次性消费。

前端仅在 `/login` 无错误且无主动退出标记时尝试自动跳转；使用 ref 防止一次挂载重复发起授权。退出统一跳转 `/login?logged_out=1`。手动点击登录仍可重新授权。

## 验收

自动化覆盖移动/桌面企微、微信与普通浏览器、未配置提供方、现有会话、错误页、主动退出及手动重试。服务端覆盖授权参数、回调state防重放、未关联拒绝和已关联登录。发布后验证公网跳转及匿名访问保护；真实企微客户端仍需本人打开应用验收，不伪造生产用户会话。

官方资料：企业微信文档91022（构造网页授权链接）和91023（获取访问用户身份）；已在本机只读获取核对。
